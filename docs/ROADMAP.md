## قرارات تنتظر صاحب المشروع

1. **مكان المستودع:** `D:\aboSobhy\OPEN PROJECT LOCAL\ipm-backend` (بجانب `ipm-web`). اسم الـ solution: `Ipm`.
2. **نموذج الصلاحيات:** نفس الواجهة: مفاتيح ثابتة بالكود، تُمنح على مستوى النظام أو داخل مشروع، مع منع صريح (default-deny). والمستخدم (`Employee` بالـ ERP) هنا `User` وهو نفسه `IdentityUser`.
3. **قاعدة البيانات:** PostgreSQL 17 + Redis 7 (نفس الـ ERP).
4. **الحد الأدنى للتسليم الأول:** الأجزاء 00–05 (مشاريع وعناصر عمل شغّالة بالكامل) قبل الموافقات وGit؟
