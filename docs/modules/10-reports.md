# الجزء 10: تقرير العمل (Excel)

> يعتمد على: الأجزاء 01–09. بيضيف تنزيل تقرير بفترة (شهر جاهز أو فترة يحدّدها المستخدم) لمشروع أو عدة مشاريع أو لشخص عبر مشاريعه.

## 1. الهدف
ملف Excel بيعطي كل مشروع (أو مجموعة مشاريع) وكل شخص صورة عمّا اشتغل عليه بالفترة. بدون جداول جديدة: قراءة فوق عناصر العمل وسجل انتقالات حالاتها.

## 2. الصلاحيات
`projects.view` **و** `reports.export` على كل مشروع داخل التقرير (نظامياً أو بدور المشروع). مشروع غير مسموح بيختفي من التقرير بدون كشف وجوده (مش 403/404). مدير المشروع وأدوار النظام اللي فيها `reports.export` بيصدّروا؛ عضو الفريق العادي لا.

## 3. الواجهة البرمجية
`GET /api/v1/reports/work?from=&to=&projectIds=&assigneeId=` ← ملف `xlsx`.

| الوسيط | المعنى |
|---|---|
| `from`، `to` | مطلوبان، يوم بتوقيت المؤسسة (شاملان). `to` ≥ `from`، والفترة حتى 366 يوماً (وإلا 400) |
| `projectIds` | قائمة معرّفات بفواصل؛ فارغة = كل مشاريعك المسموحة؛ معرّف غير صالح ← 400 |
| `assigneeId` | يحصر التقرير بعناصر هذا الشخص (مسندة إليه)؛ غير موجود ← 404 |

## 4. القواعد
| # | القاعدة |
|---|---|
| R1 | النطاق = المشاريع المسموحة (الباب 2) ∩ `projectIds` إن وُجدت |
| R2 | عنصر العمل (غير المؤرشف) بيدخل إذا **أُنشئ** بالفترة، أو **انتقلت حالته** بالفترة (سجل `WorkItemStatusChange`)، أو **تحدّث** بالفترة (`UpdatedAt`). مع `assigneeId`: العناصر المسندة إليه فقط |
| R3 | **سبب الإدراج:** «جديد» إن أُنشئ بالفترة، «أُنجز» إن انتقل لفئة Done بالفترة، «تغيّرت حالته» لأي انتقال آخر، «تحديث» إن اقتصر على تعديل |
| R4 | **الملف:** ورقتان من اليمين لليسار: **الملخص** (الفترة والشخص وتاريخ الإصدار، وسطر لكل مشروع: عناصر تأثّرت بالفترة، جديدة، أُنجزت، مفتوحة الآن، متأخرة الآن، مع إجمالي)، و**عناصر العمل** (المرجع، المشروع، العنوان، النوع، الحالة، الأولوية، المكلَّفون، البداية، الاستحقاق، أُنشئ، آخر تحديث، متأخر، سبب الإدراج) بفلتر وتثبيت الرأس |
| R5 | نص يبدأ بـ `=` أو `+` أو `-` أو `@` بيتحفظ كنص ولا يُنفَّذ كصيغة. الحد 20,000 عنصر (أكثر ← 422 `Report.TooLarge`، ضيّق الفترة) |

## 5. الواجهة (ipm-web)
تبويب «تنزيل تقرير العمل» بصفحة التقارير (لمن يملك `reports.export`): فترة (الشهر الحالي، الشهر الماضي، آخر 30 يوماً، آخر 3 أشهر، أو من–إلى)، المشاريع (كلها أو اختيار عدة مشاريع)، والشخص (اختياري). الاسم: `تقرير-العمل-<من>_<إلى>.xlsx`.

## 6. سيناريوهات القبول
1. تقرير مشروع بفترة تحوي اليوم ← فيه عناصره وسطر ملخص صحيح.
2. فترة بلا نشاط ← ورقة العناصر فارغة.
3. عدة مشاريع ← كلها بالتقرير، وكل مشروع لحاله بيعطي عناصره فقط.
4. تقرير شخص عبر مشروعين ← عناصره فقط، واسمه بالملخص.
5. عنوان `=1+1` ← يبقى نصاً.
6. عضو بدون `reports.export` أو غريب عن المشروع ← تقرير فارغ بدون كشف.
7. فترة مقلوبة أو أطول من 366 يوماً أو معرّف مشروع غير صالح ← 400؛ شخص غير موجود ← 404؛ بدون دخول ← 401.
